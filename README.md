## 仓库约定

### 目录结构

```
learning-log/
├── README.md          本文件（门面 + 总目录）
├── daily/             每日日志，文件名格式 YYYY-MM-DD.md
├── notes/             专题笔记，按主题命名
├── ctf/               题目记录
└── _templates/        模板文件
```

### 提交信息前缀

| 前缀 | 用途 |
| --- | --- |
| `log:` | 日常日志 |
| `note:` | 专题笔记 |
| `ctf:` | 题目记录 |
| `chore:` | 杂项（改 README、配置等） |

### 日常流程

```bash
git add .
git commit -m "log: YYYY-MM-DD 学习记录"
git push
```
