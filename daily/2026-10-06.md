### SQL数据库的基本信息:
SQL数据库分为关联型数据库和非关联式数据库,常见的关联式数据库有MYSQL,Oracle,PostgreSQL等<br>
常见的非关联式数据库有MongoDB,Redis,DynamoDB等<br>
使用create datebase 数据库名; 来创建数据库<br>
使用 Use 数据库名; 来指定数据库进行操作<br>
使用 create table 表格名(<br>
  列名1 int,<br>
  列名2 varchar(),<br>
  列名3 date<br>
);
使用Auto_increment可以自动递增数据<br>
一般要设置primary key 保证列名不重复<br>
插入数据使用insert into 数据库名.表格名(列名1,列名2,列名3)values(数值1,数值2,数值3);<br>
varchar和date中的字符要用引号括起来<br>
数值可以用default表示默认值<br>
alter table 数据库名.表格名;改变表格用<br>
add 列名 数据类型 默认条件;新增用<br>
update 数据库名.表格名<br>
set 值<br>
where 条件<br>
