### PHP的学习报告  
对于PHP的变量作用域,存在共四种不同的变量作用域分别为:  
1. local
2. global  
3. static  
4. parameter
#### 对于作用域和定义函数的讨论
在所有函数外部定义的变量,拥有全局作用域,要在一个函数中访问一个全局变量需要使用global关键字  
在php函数内部声明的变量是局部变量,仅能在函数内部访问.  
在php中我们使用function来定义一个函数  
例:  
function 变量名(参数){    
echo"变量名";  
}  
上文定义了一个函数,function后跟上变量名同时跟括号,括号中放置参数,当然可以不填则不返回参数  
同时花括号中的代码块则是这个函数所需运行的程序  
本质上定义一个新函数是为了防止重复书写代码块所使用的一种偷懒的方式  
这种方法适用于长期的项目  
有一个重要的点是不要忘记调用函数,一个函数在定义完成以后不会自动使用需要你对它进行调用  
#### 对于global关键字的使用
由于作用域的关系所以变量不能跨函数内外混用  
但是global关键字提供了一种方法使得函数内可以调用函数外的变量  
只需要在函数内打出global $全局变量一号,$全局变量二号;
则可以在函数内调用函数外的变量  
php将全局函数保存在一个名为$GLOBAL[index]的数组中index保存变量名称  
该数组可以直接在函数内访问,也可用于更新数据.
