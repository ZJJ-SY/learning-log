### 极客大挑战2023-web-esay_php
```php
<?php
header('Content-type:text/html;charset=utf-8');
error_reporting(0);

highlight_file(__FILE__);
include_once('flag.php');
if(isset($_GET['syc'])&&preg_match('/^Welcome to GEEK 2023!$/i', $_GET['syc']) && $_GET['syc'] !== 'Welcome to GEEK 2023!') {
    if (intval($_GET['lover']) < 2023 && intval($_GET['lover'] + 1) > 2024) {
        if (isset($_POST['qw']) && $_POST['yxx']) {
            $array1 = (string)$_POST['qw'];
            $array2 = (string)$_POST['yxx'];
            if (sha1($array1) === sha1($array2)) {
                if (isset($_POST['SYC_GEEK.2023'])&&($_POST['SYC_GEEK.2023']="Happy to see you!")) {
                    echo $flag;
                } else {
                    echo "再绕最后一步吧";
                }
            } else {
                echo "好哩，快拿到flag啦";
            }
        } else {
            echo "这里绕不过去，QW可不答应了哈";
        }
    } else {
        echo "嘿嘿嘿，你别急啊";
    }
}else {
    echo "不会吧不会吧，不会第一步就卡住了吧，yxx会瞧不起你的！";
}
?>
```
以上是题目信息,现在开始解题
#### 题解:
1. 使用get方法发送syc=welcome to GEEK 2023!因为在正则匹配中含有/i所以可以忽略大小写这样就可以通过正则匹配的同时,通过后面的不等于
2. 使用get方法发送lover=1e4这样在第一个intval()函数中输出1,因为将其识别为字符串的方法转义,后面的由于有运算所以会将1e4识别为科学计数法从而满足后面
3. 使用post方法发送qw[]=&yxx[]=这样就可以绕过sha1的比较因为,sha1对于数组的转义为array所以严格比较后成立
4. 使用post方法发送SYC[GEEK.2023=Happy to see you!这样可以避免.被转义[后的内容与前文分开前面的被转义,后面直接拼接,同时由于没有后括号所以[会被自动转化为_这样就拿到了目标变量名
