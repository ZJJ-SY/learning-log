### php数据类型比较
php变量可储存不同类型的数据,支持以下类型:
1. string(字符串)
2. integer(整形)
3. float(浮点型)
4. boolean(布尔型)
5. array(数组)
6. object(对象)
7. Null(空值)
8. resource(资源类型)

### php类型比较
- 松散比较:使用两个==比较,只比较值,不比较类型
- 严格比较:使用三个===比较,值和类型都要比较

在松散比较下:0 = false ; false = null ; 0 = null ; "0" = false ; "0" != null ; "" = false : "" = null<br>
在严格比较下:0 != false ; 0 != null ; null != false ; "0" != false ; "0" != null ; "" !=false ; "" != null<br>
在松散比较中:1 = true ; -1 = true<br>
### php常量:
与变量不同,数据固定,使用define()函数,函数语法如下<br>
```php
bool define(string $name,mixed $value,bool $case_insensitive = false)
```
该函数有三个参数:
- name:必选,常量名称,即辨识符
- value:必选,常量的值
- case_insensitive:可选,如果设置为为TRUE,则该常量大小写不敏感,反之则大小写敏感.默认为大小写敏感(false)
