### php中的static作用域
当一个函数完成工作时,通常其所有变量会被删除.若希望其某个局部变量不要被删除    
即可在函数中声明变量时使用static关键字  
列:
```php
<?php  
function myTest(){
static $x = 0;
echo $X;
$x++;//等同于$x = $x + 1
echo PHP_EOL;
}
myTest();  
myTest();  
myTest();  
?>  
```
若不使用static关键字则输出不同行的三个0,若加上static关键字则输出不同行的0 1 2  
即每次调用static声明的变量时,变量保持上一次调用完成的值  
当然该变量任然是该函数的局部变量  
### php中的参数作用域
参数是通过调用代码将值传递给函数的局部变量  
参数是在函数列表中声明的,作为函数声明的一部分:  
```php
<?php
function mytest($x){
echo($X);  
}  
mytest(5);//输出5  
?>
```
### php的基本输出方式与对比
php中的基本输出方式有两种,分别是echo函数和print函数.  
#### echo与print语句的区别  
echo语句可以输出一个或者多个字符串  
print语句只允许输出一个字符串,且返回值总为1  
另外echo输出的速度比print语句快,echo没有返回值  
echo语句可在多个变量间使用"."或者","进行分割  
综上在实际输出结果时我们总是使用echo语句而不是print语句
