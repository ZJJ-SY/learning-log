### C语言的基本结构
我将使用一个书上的例子来形象说明C语言的基本结构并且我的有关想法会以注释的方法批注出来.
例:  
#include<stdio.h>  
/*该行告诉编译器把stdio.h中的内容包含在当前程序中.stdio.h是C编译器软件包的标准部分,它提供键盘输入和屏幕的输出的支持*/  
int main(void)  
/* int表明main函数返回一个整数,void表示main函数不带任何参数*/  
{  
/*前花括号表示函数的定义开始后花括号表示函数的定义结束*/  
int num;  
/*声明将使用一个名为num的变量,且num为整数型*/  
num = 1;  
/*把值1赋值给变量num*/  
printf("I'm a man");  
printf("computer.\n")  
/*"\n"表示输出的换行操作*/  
prinf("1%d",num);  
/* %d为占位符,提示了如何将变量输出,变量以何种方式输出,打印在何处*/  
return 0;  
/*main函数返回值为0*/  
}  
//这种注释为单行注释只能写一行  
/*这种注释为多行注释  
可以写多行*/  
### PDP的基本规则  
PHP的相关笔记我也同样会附带相关的列子,有助于相关理解,并且由于PHP和C语言中注释的方法基本一致所以我在PHP中同样使用注释表明相关理解  
列:  
<?php  
//PHP中以< ? php来表明php脚本开始,以 ? >来表明php脚本的结束  
$a = 1111;  
//在PHP中使用$变量名的方法来声明一个变量,值得注意的的是php中不需要对于变量的属性进行声明,在赋值时会自动对于变量进行分类  
echo $a;  
?>  
在php中基本的输出函数有两个分别是echo和print这两个有着一定的区别但是在日常使用中更倾向于使用echo因为它的响应速度更快.
